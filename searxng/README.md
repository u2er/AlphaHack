# Поиск и разбор веб-страниц (не используется в текущем приложении)

В этой папке лежит прототип сбора материалов из интернета. Его основная часть — поиск ссылок через SearXNG и извлечение текста **отдельной страницы по URL**. Сейчас модуль не подключён к `profile`.

## Как устроен сбор

1. [`search.py`](search.py) отправляет поисковый запрос в JSON API SearXNG (`/search`). Он получает ссылки, заголовки и сниппеты, удаляет повторы и при необходимости оставляет только заданные домены. Сниппет служит подсказкой для выбора ссылки, но не считается текстом документа.
2. [`parser.py`](parser.py) по каждой выбранной ссылке делает HTTP-запрос и извлекает содержимое ответа. Для HTML он ищет текст статьи в `articleBody` из JSON-LD, в `<article>` или основном блоке страницы; также пытается получить заголовок, дату публикации и автора. Поддерживаются обычный текст и PDF с текстовым слоем.
3. [`agent.py`](agent.py) связывает поиск и парсер: формирует поисковые задачи, загружает найденные страницы и передаёт извлечённые документы в [`indexer.py`](indexer.py). Дальнейшая оценка собранных материалов — часть этого прототипа, а не функция SearXNG или парсера.

SearXNG **ищет URL**, а `DocumentParser.fetch(url)` **скачивает и разбирает конкретный URL**. Парсер можно вызвать и для известной ссылки без поиска в SearXNG. Полного обхода сайта, автоматического поиска всех его статей через RSS или sitemap здесь нет.

## Возможности и ограничения парсера

- Результат — `ParsedDocument` из [`models.py`](models.py): URL, заголовок, извлечённый текст, дата и автор при наличии, тип содержимого, время загрузки и хеш исходного ответа.
- Загрузка ограничена 5 МБ на ответ; PDF — 200 страницами. Короткие страницы (менее 160 символов извлечённого текста) отбрасываются.
- Ссылки на локальные и непубличные сетевые адреса блокируются; переходы по перенаправлениям проверяются повторно.
- JavaScript страницы не исполняется, OCR для сканированных PDF нет. Если сайт отдаёт только заглушку или текст появляется после выполнения JavaScript, извлечь статью не получится.
- Автоматического обновления ранее сохранённой страницы нет: повторно найденный URL прототип обычно берёт из своей базы.

Конфигурация SearXNG для прототипа находится в [`deploy/searxng`](../deploy/searxng). Код в этой папке сохранён как отдельная заготовка; его старые CLI и хранилище не являются частью текущего сценария профиля компании.
