# Интерфейс «Альфа-Бизнес»

Прототип интернет-банка Альфа-Бизнес для бизнес-аналитики. Работает в браузере на стандартном `http.server` Python, без отдельных зависимостей.

- **Главная** — демонстрационные счета (помечены «демо») и заметная точка входа в бизнес‑аналитику с главными событиями дня.
- **Бизнес‑аналитика** — лента выбранной компании (`GET /profiles/{id}/feed` EventGraph): важность для клиента, риск или возможность, горизонт. В карточке события источники разведены: `AI` — интерпретация аналитика для этой компании и что можно сделать; `Альфа‑Банк` — близкие по смыслу фрагменты отчётов аналитиков банка из библиотеки `profile_data` (с датой и страницей, старые помечены как исторические); `Источник` — первоисточник новости и событие в графе. Фильтры — риски/возможности и порог важности; над лентой — подтверждённые темы наблюдения из профиля.
- **Профиль компании** — мастер профиля (ниже); после сохранения профиль уходит в EventGraph и компания появляется в переключателе.
- Счета, платежи, зарплата и кредиты — заглушки.

Ленту GUI берёт у EventGraph сам: `EVENTGRAPH_URL` (в compose — `http://api:8000`) и `API_KEY`; браузер ключа не видит (`gui/insights.py`).

## Мастер профиля

Названия полей и подписи кодированных значений GUI получает из справочников PostgreSQL. В раскрываемом списке исходных данных видны и человекочитаемые подписи, и исходные ключи со значениями; экспортный JSON сохраняет машинный формат. База — схема `profile_data` в Postgres EventGraph; подготовьте её по `profile/db/README.md`.

В compose GUI поднимается вместе с остальным (`eventgraph-profile-gui`) и открыт на [http://127.0.0.1:8765/](http://127.0.0.1:8765/) (порт — `PROFILE_GUI_PORT`). Экспорт попадает в общий том `/profiles`, откуда его загружает воркер EventGraph; проходы — в `/data/gui-runs` (`GUI_RUNS_DIR`).

С хоста, из корня репозитория:

```bash
PROFILE_DATABASE_URL=postgresql://eventgraph:eventgraph@127.0.0.1:5433/eventgraph .venv/bin/python -m gui
```

Для другого порта: `--port 8766`. Сервер слушает `127.0.0.1` (`--host 0.0.0.0` — только внутри контейнера); для остановки нажмите Ctrl-C в его терминале.

1. Найдите обезличенную компанию по ID, отрасли или региону. Черновик сформируется автоматически. При ручном создании раскройте список полей, заполните только известные и нажмите «Готово, сформировать черновик».
2. Сразу под черновиком находится раскрываемый список полей и сигналов. После правки поля черновик можно обновить кнопкой над ним.
3. Исправляйте отдельные поля кнопкой «Сохранить» или напишите фразу в поле правки. Во втором случае модель предложит ключ и значение для подтверждения. Ответьте на полезные вопросы, остальные пропустите и подтвердите профиль.
4. Подтвердите профиль: агент запустится автоматически. Страница сама обновляет статус; если агент задаст вопрос, ответьте в появившейся карточке. Просмотрите темы, ссылки на фрагменты и ограничения, удалите лишние темы либо подтвердите результат. После ошибки можно повторить подбор тем.
5. Сохраните необязательные сайты и откройте итоговый JSON. Его можно скачать; при заданном `PROFILES_DIR` он сразу передаётся EventGraph, и аналитик начинает оценивать новости для этого клиента.

Кнопка «Начать сначала» сбрасывает текущий экран и позволяет выбрать другую компанию. Предыдущие файлы прохода в `gui/runs` остаются на диске.

Раздел «Ход работы» показывает последние события полного журнала: запросы и ответы LLM, результаты обращения к БД, валидацию, вопросы и подтверждения. Каждый проход сохраняется в `gui/runs/<session-id>/`: `draft.json`, `trace.jsonl` и после экспорта `export.json`. Каталог исключён из Git; журнал содержит значения профиля и ответы пользователя. Перезагрузка страницы в рамках работающего сервера сохраняет текущую сессию в браузере. После перезапуска сервера начните новый проход; файлы прежних проходов остаются на диске.

Черновик, правки словами и агент используют LLM из `.env`. Выбор компании и просмотр исходных полей работают без вызова LLM. Источники новостей и загрузка пользовательских документов не подключены.

Проверки:

```bash
.venv/bin/python -m pytest tests/tests_gui
```
