# Парсеры входных данных

`csv.py` читает CSV приложения 1 с разделителем `;` и кодировкой UTF-8. `loader.py` подключает переданный индексатору модуль из пакета `parser`.

Обработчик PDF приложения 2 добавляется отдельно. Его функция принимает `path: Path` и возвращает `date_hint` и список страниц с `page`, `text`, `extraction`. Точный формат и команда запуска описаны в [profile/db/README.md](../profile/db/README.md). OCR и кэш, если нужны, реализуются в подключаемом обработчике.
