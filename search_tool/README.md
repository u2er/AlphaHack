# Интернет-поиск для агента

`InternetSearchTool` принимает запрос, получает URL через SearXNG, скачивает страницы,
извлекает текст и возвращает наиболее близкие к запросу фрагменты **с каждой страницы**.
LLM внутри тулла нет. Агент сам оценивает доказательства и при необходимости вызывает
тулл с уточнённым запросом.

```python
from search_tool import InternetSearchTool, TOOL_DEFINITION

with InternetSearchTool() as tool:
    result = tool("экспорт древесины из России в Китай 2026", category="news")
    # result — JSON-совместимый dict; передайте его вызывающему агенту.
    # TOOL_DEFINITION — описание функции internet_search и JSON Schema аргументов.
    # В диспетчере вызовов: result = tool(**arguments)
    if result["sources"]:
        full_source = tool.read_source(result["sources"][0]["source_id"])
```

Для зарегистрированной функции `internet_search` используйте `TOOL_DEFINITION`.
Вызовы и продолжение рассуждения выполняет внешний агент. Текущий `profile` к туллу
автоматически не подключается. `read_source` — дополнительный Python API для чтения
сохранённого источника; в `TOOL_DEFINITION` зарегистрирован только интернет-поиск.

## Запуск

Установите корневой `requirements.txt`. Нужны доступный SearXNG с JSON-выдачей
и локальная `models/multilingual-e5-large` (можно передать `e5_path`). Модель
загружается при первом непустом результате поиска, автоматических скачиваний нет.

```bash
python -m search_tool "экспорт древесины из России в Китай 2026" \
  --max-results 6 --fragments-per-source 3 --category news --time-range month
```

CLI читает `.env`. Python API использует окружение процесса и сам `.env` не читает.
Адрес берётся из `base_url`, затем `SEARXNG_BASE_URL`, по умолчанию
`http://127.0.0.1:8082` — порт `deploy/searxng/compose.yaml`.
У HTTP-клиентов SearXNG и загрузчика страниц **`verify=False`**.

## Какие фрагменты возвращаются

Весь извлечённый текст группируется по целым предложениям с ориентиром 448
токенов E5 на фрагмент. Перекрытие — целые предложения суммарно до 64 токенов.
Учитываются распространённые сокращения и десятичные числа. Очень длинное
предложение сохраняется целиком; для E5 оно кодируется окнами до 448 токенов,
после чего векторы усредняются и нормализуются. Хвост текста не обрезается.
Текст без пунктуации и последняя незавершённая фраза сохраняются как есть. Все символы извлечённого текста покрыты, включая короткий
последний фрагмент. Короткая страница с непустым текстом также обрабатывается.
Затем E5 кодирует запрос с префиксом `query: ` и **все** фрагменты с `passage: `.
Результат ранжируется по косинусной близости отдельно для каждой страницы.
По умолчанию возвращаются 3 лучших фрагмента с каждого из максимум 6 URL.
Число фрагментов — верхняя граница. E5Ranker оставляет фрагменты с score >= 0.84
и отставанием от лучшего фрагмента страницы не более 0.025. Это настраиваемые
эвристики (`min_score`, `max_score_gap`), а не гарантия релевантности. Возможен
пустой список с `selection_status=no_relevant_fragments`; все фрагменты по-прежнему
доступны через `read_source`. Если ни один источник не дал фрагментов, status=empty.

`sources[].fragments[]` содержит `id`, `source_id`, `text`, `score`, `url`, `title`,
`published_at`, `ordinal`, `start`, `end`. Позиции — индексы символов в извлечённом
тексте, полуинтервал `[start, end)`. Дата может быть `null`; дата из поискового
сниппета не подставляется вместо даты страницы. Сниппеты не попадают в доказательства.
`score` показывает близость по смыслу и не является вероятностью достоверности.

**БД не используется: тулл ничего не записывает ни в БД, ни в файлы.**
Перенаправление CLI-вывода в JSON-файл — отдельное действие вызывающего процесса.

Полный текст и все фрагменты остаются в памяти экземпляра; доступны через
`read_source(source_id)`. ID привязан к URL и хешу загруженного содержимого.
Повторный запрос снова ищет и загружает страницы, поэтому изменившийся источник
получает отдельный снимок. `clear()` освобождает снимки. Данные не сохраняются на диск
и недоступны после завершения процесса; для нескольких вызовов сохраняйте один экземпляр.

## Ошибки и ограничения

Ответ содержит `status`, `sources`, `failures`, `warnings`. `ok` означает успешный
сбор, `partial` — есть источники, но были ошибки/предупреждения, `empty` — нет URL,
`error` — ошибка поиска или не удалось прочитать ни одной страницы. Ошибка одной
страницы не мешает обработке остальных. Неверные аргументы и отсутствие локальной
модели вызывают исключение, которое должен обработать диспетчер агента.

Поддерживаются HTML, обычный текст и PDF с текстовым слоем. Из HTML извлекается
содержимое статьи/основного блока, служебная разметка удаляется; сохранение всех
фрагментов относится к **извлечённому тексту**, а не ко всему HTML. JavaScript и OCR
не выполняются. Лимиты: 5 МБ ответа, 200 страниц PDF, максимум 5 HTTP-переходов.
Непубличные адреса и нестандартные порты страниц блокируются, перенаправления
проверяются повторно. Поиск использует первую страницу SearXNG; домены фильтруются
после получения выдачи. Текст источников нужно передавать агенту как недоверенные данные.

HTML: удаляются блоки меню, подписок, рекомендаций, комментариев и рекламы;
выбирается один основной контейнер статьи, а не все теги article на странице.
Подписи к фото удаляются по разметке `figcaption`, классам подписей и
кредитов изображений, включая `.block-image .description`; обычные абзацы
с упоминанием фотографий сохраняются.
Очистка эвристическая и может потребовать адаптации к другим сайтам.

Заголовок выбирается из citation_title / DC.title, затем og:title и HTML-заголовка.
Концевые разделы с отдельными заголовками «Библиографическая ссылка», «Список
литературы», «Библиография», References и Bibliography исключаются из текста HTML.
После общего ранжирования минимум 30% символов фрагмента должны принадлежать
предложениям с E5 score >= min_score (`min_support_ratio` настраивается).
Для предложений длиннее окна E5 применяется общая оценка фрагмента по всем окнам.
Внутри страницы исключаются фрагменты с пересекающимися позициями или сходством
множеств слов более 0.6. Это эвристики: они могут исключить полезный контекст и
не гарантируют смысловую релевантность. Все извлечённые фрагменты остаются в памяти.
